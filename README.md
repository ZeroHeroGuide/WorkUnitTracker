# Work Unit Tracker

A game-style work unit tracker for GloBird sales agents.

**Live site:** https://zeroheroguide.github.io/WorkUnitTracker/

- 🎮 Tap calls hour by hour and chase 7.3 WU an hour (55 a day)
- ⚖️ Hours-weighted average — short days, Saturdays and leave handled fairly
- 🎯 Catch-up target when you're under goal
- 📈 Stats for every month: calendar, best weekday and hour, call mix, records and badges
- 💨 A talking mascot with very strong opinions
- 💾 CSV export/import to move your data between versions or computers

Everything runs in the browser. Each agent's data is stored privately in their own browser — nothing is sent anywhere.
